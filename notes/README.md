# Practice Notes

One note per practice session. These are the highest-signal artifact for interview
prep: writing the trade-off down in your own words is what makes it come out fluently
when you are asked out loud.

- Copy `_template.md` to `YYYY-MM-DD-topic.md` at the end of each session.
- `2026-07-02-java-01-idempotency-cache.md` is a filled-in example that matches the
  worked reference code under `collections/`.
- Some `DESIGN-*` and `PROD-*` exercises produce their own artifact here (design
  docs, runbooks, a behavioral story bank) rather than a session note.
